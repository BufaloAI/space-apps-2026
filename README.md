# space-apps-2026
Main repository of BufaloAI Team in NASA Space Apps 2026

## Klasörler
- [`backend/`](backend/README.md): API, vLLM köprüsü, kurulum ve çalıştırma
- [`frontend/`](frontend/README.md): BufaloAI küresel harita, dönemsel analitik, veri gezgini ve canlı parsel analizi
- `ml/`, `data-load/`: model ve veri hazırlama çalışmaları

Backend'i çalıştırmak için [`backend/README.md`](backend/README.md), frontend yazanlar için [`backend/frontend-spec.md`](backend/frontend-spec.md).
